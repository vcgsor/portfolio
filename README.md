## 04｜数据分析与代码实践

### 喜茶新品：消费者偏好与定价分析

**项目类型：小组课程项目。**

**我的职责：负责数据分析与代码实现，包括描述性分析、联合分析（Conjoint Analysis）、购买意向的二元 Logit 回归、购买频次的有序 Logit 回归，以及最终条形图等结果可视化与相关代码附件。**

通过产品属性偏好、价格接受度、购买意向与频次分析，支持团队讨论新品定位、定价及营销方案。

**数据说明：项目使用 300 个 AI 模拟受访者进行分析，属于模拟数据方法实践，不代表真实消费者调研或真实市场验证。**

在线预览 PDF：[喜茶新品偏好与定价分析](https://github.com/vcgsor/portfolio/blob/main/heytea-analysis.pdf)

## 05｜毕业研究：强化学习俄罗斯方块 Agent

**项目类型：本科毕业研究。**

以俄罗斯方块为实验环境，探索强化学习 Agent 的状态表示、动作选择与奖励设计。项目使用四维棋盘特征与价值网络，包含游戏环境、训练记录、模型保存及可视化实现。

论文与历史代码训练输出均记录单回合最高消除 468 行。这是历史实验的最高记录，不代表平均表现或独立复现结果。

附件保留原始毕业论文；当前代码版本的 Double DQN 选择与评估实现仍需进一步复核，因此本导览使用“强化学习 Agent”概括项目。
