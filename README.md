## 02｜内部产品经历

### 小红书 Creative AI

面向海外 App 营销素材生产场景，参与需求分析、产品设计与研发协同，推动两个核心版本迭代。参与图片、视频及 TTS 模型选型，并围绕分步生成、素材复用与操作简化优化内容生产体验。

### 美团 Keeta 权限申请 Agent

围绕权限申请、申请进度查询、个人权限查询及同事权限参考等场景，梳理用户意图与权限数据结构，设计结合关键词和语义检索的混合召回方案，并通过去重、重排、推荐阈值与澄清机制优化推荐体验。

以上均为内部产品，本作品集仅提供经历与职责介绍，不展示产品界面、内部流程图及相关材料。

## 04｜数据分析与代码实践

### 喜茶新品：消费者偏好与定价分析

**项目类型：小组课程项目。**  
**我的职责：数据分析与代码实现。**

负责描述性分析、联合分析（Conjoint Analysis）、购买意向的二元 Logit 回归、购买频次的有序 Logit 回归，以及结果可视化与相关代码附件。通过产品属性偏好、价格接受度、购买意向与频次分析，支持团队讨论新品定位、定价及营销方案。

**数据说明：项目使用 300 个 AI 模拟受访者进行分析，属于模拟数据方法实践，不代表真实消费者调研或真实市场验证。**

[查看 PDF｜喜茶新品偏好与定价分析](https://github.com/vcgsor/portfolio/blob/main/heytea-analysis.pdf)

### 游戏市场表现分析

**项目类型：小组课程项目。**  
**我的职责：代码负责人。**

承担项目代码实现工作，支持团队探索游戏特征与市场表现之间的关系。材料呈现小组整体研究框架、分析方法与结果。

[查看 PDF｜游戏市场表现分析](https://github.com/vcgsor/portfolio/blob/main/game-market-analysis.pdf)

### 在线零售：客户分层与个性化推荐

**项目类型：小组课程项目。**  
**我的职责：项目负责人。**

结合 RFM 客户分层与 Apriori 关联规则，探索差异化营销和商品推荐策略。演示文稿用于快速了解项目；报告提供数据处理、分析方法、评估与营销建议的详细说明。

**结果说明：推荐指标来自离线评估，不代表上线业务增长；模型与基线的有效验证样本量不同，比较结果需结合覆盖范围理解。**

- [查看 PDF｜零售客户分层与推荐演示文稿](https://github.com/vcgsor/portfolio/blob/main/retail-presentation.pdf)

## 05｜毕业研究：强化学习俄罗斯方块 Agent

**项目类型：本科毕业研究。**

以俄罗斯方块为实验环境，探索强化学习 Agent 的状态表示、动作选择与奖励设计。项目采用四维棋盘特征与价值网络，包含游戏环境、训练记录、模型保存及可视化实现。

论文与历史代码训练输出均记录单回合最高消除 468 行。这是历史实验的最高记录，不代表平均表现或独立复现结果。

材料保留原始毕业论文。当前代码版本的 Double DQN 选择与评估实现仍需进一步复核，因此本导览以“强化学习 Agent”概括项目。
