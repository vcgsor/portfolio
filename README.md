## 04｜数据分析

### TATA 在线零售｜客户分层与个性化推荐

**小组项目，我担任项目负责人。**

这是简历“项目经历”中介绍的零售分析项目。我们基于英国零售商约 39.6 万条交易数据，完成数据清洗与特征构建，使用 RFM 模型划分客户，再通过 Apriori 关联规则挖掘商品组合，讨论不同客户群的营销与推荐方案。

建议先看演示文稿了解项目，再看报告中的数据处理、评估方法和营销建议。

- [查看 PDF｜客户分层与推荐演示文稿](https://github.com/vcgsor/portfolio/blob/main/retail-presentation.pdf)
- [查看 PDF｜客户分层与推荐项目报告](https://github.com/vcgsor/portfolio/blob/main/retail-report.pdf)

推荐结果来自离线评估，不代表上线后的业务增长。模型与基线的有效验证样本量不同，比较指标时需要结合覆盖范围理解。

### 喜茶新品｜消费者偏好与定价分析

**小组项目，我负责数据分析与代码实现。**

围绕新品的产品属性、价格接受度、购买意向与购买频次，我完成描述性分析、联合分析、二元 Logit 回归和有序 Logit 回归，并制作结果图表，供团队讨论新品定位与定价方案。

[查看 PDF｜喜茶新品偏好与定价分析](https://github.com/vcgsor/portfolio/blob/main/heytea-analysis.pdf)

本项目使用 300 个 AI 模拟受访者的数据，用于分析方法练习，不是真实消费者调研。

## 05｜毕业论文

### 强化学习俄罗斯方块 Agent

我以俄罗斯方块为实验环境，研究 Agent 的状态表示、动作选择和奖励设计。项目采用四维棋盘特征与价值网络，包含游戏环境、训练记录、模型保存及可视化实现。

[查看 PDF｜毕业论文](https://github.com/vcgsor/portfolio/blob/main/tetris-thesis.pdf)

论文与历史训练输出记录的单回合最高成绩是消除 468 行，这是历史实验中的最高记录，不代表平均表现。当前代码版本的 Double DQN 选择与评估实现仍需进一步复核，因此这里使用“强化学习 Agent”作为项目名称。
